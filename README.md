# KlikBand · AstroBox

AstroBox release files for [KlikBand](https://github.com/ashafizullah/klikband), a free, open-source
Vela quick app for Muslims (prayer times, dhikr, tasbih, Hijri calendar) on Xiaomi Smart Band,
REDMI Watch and Xiaomi Watch.

KlikBand 的 AstroBox 发布仓库。源代码见 [ashafizullah/klikband](https://github.com/ashafizullah/klikband)。

Community quick app, not an official Xiaomi product. 社区制作的 Vela 快应用，非小米官方产品。
